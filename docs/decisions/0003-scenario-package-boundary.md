# ADR 0003：剧本包只通过初始事件进入世界

## 状态

已接受，2026-08-19。

## 背景

演示世界最初直接写在 Python 初始化函数中。继续这样扩展会让更换剧本等同于修改规则代码，也会让初始状态绕过事件审计。

## 决策

- 剧本内容放入独立、多文件、带 Schema 版本的 JSON 剧本包；
- 加载时校验结构、重复 ID 和跨文件引用；
- 对实际内容计算 SHA-256 指纹；
- 剧本包通过纯 Python 编译器转换成初始确认事件；
- 存档固定记录剧本标识、版本和内容指纹；
- 剧本包不得直接更新运行中的当前状态；
- 已有存档只通过显式迁移升级，不跟随磁盘内容静默变化。

## 结果

纯内容更换不再要求修改初始化代码，初始世界也能完整重放和审计。代价是作者必须维护引用完整性，且未来更改剧本结构时需要明确的 `schemaVersion` 迁移策略。
