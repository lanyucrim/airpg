# ADR 0004：NPC 交付与礼物接受必须显式授权

## 状态

已接受，2026-08-19。

## 背景

通用化物品请求时，如果简单规定“非管制物品都会交给玩家”，NPC 会失去所有权和行为边界。如果把“接受礼物”写成物品属性，又会导致任何 NPC 都自动接受同一种礼物。模糊名称如果由系统猜测，还可能转移错误的唯一物品。

## 决策

- `owner_discretion` 是请求的默认策略，未显式授权时不转移物品；
- `allow` 只表示剧本作者明确允许持有人交付该物品；
- 管制物品继续拒绝，并可以通过剧本配置替代线索；
- 接受礼物由接收角色的 `acceptedGiftDefinitionIds` 决定，而不是由物品单方面决定；
- 未声明接受时只记录提出和拒绝，不转移物品；
- 多个实体同样匹配时返回结构化歧义，不能任选一个；
- 玩家明确点名的目标优先，目标未持有物品时明确失败，不能暗中改成真正持有人。

## 结果

NPC 的物品和同意权不会被通用规则默认为玩家可取。代价是当前规则在信息不足时偏保守；未来可由经过校验的 NPC 决策候选补充，但候选仍不能绕过物品、位置和容器校验。
