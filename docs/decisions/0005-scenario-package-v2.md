# ADR 0005：剧本包 v2 与原稿编译边界

状态：部分被 ADR 0006 取代（v2 结构兼容保留，旧演示保留决策已废止）  
日期：2026-08-19

## 背景

《灰港：黑潮王座》原稿有 24,137 行，包含七幕主线、备用路线、随机事件、GM 真相、NPC 私密动机、组织资产、法律流程和终局建议。旧版剧本包只能表达平面地点、角色、物品、关系、线索和单个场景，且原 `gray-harbor` 目录实际保存的是守卫与红酒演示。

如果把整份 Markdown 直接送给模型或写入公开状态，会同时产生三个错误：玩家提前知道 GM 真相；尚未发生的可能剧情被误当事实；更换剧本继续依赖 Python 硬编码。

## 决策

1. 保留剧本包 v1 兼容能力，旧演示迁移到 `guard-wine-demo`。
2. 正式《灰港》使用剧本包 v2。
3. v2 增加层级地点与显式出口、组织、客观事实、时钟、义务、角色公开/私有资料和战役历法。
4. 原稿是内容来源，不是运行时指令，也不是已经发生的世界状态。
5. 只把经过结构校验、引用校验、秘密边界检查和验收测试的切片编译为初始事件。
6. 所有新增状态仍通过事件进入投影，不允许剧本包直接更新当前状态。

## 结果

优点：

- 真实剧本可以逐步导入，不需要重写规则引擎；
- GM 真相与玩家状态有明确边界；
- 七日期限和债务不再只存在于叙述里；
- 旧演示继续用于回归，不会丢失既有验证能力。

代价：

- v2 文件更多，内容作者需要维护引用；
- 原稿更新不会自动改变已编译切片；
- 需要后续实现显式内容迁移和原稿到剧本包的辅助工具。

## 迁移影响

现有 v1 包继续加载。`gray-harbor` 的 `scenarioId` 改为 `gray-harbor-black-tide-throne`，因此它是新的正式剧本模板，不会静默覆盖旧 `gray-harbor` 演示存档。旧演示使用 `guard-wine-demo` 标识。
