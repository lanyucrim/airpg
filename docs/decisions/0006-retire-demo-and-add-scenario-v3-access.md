# ADR 0006：移除旧演示并使用剧本包 v3 表达访问与发现

状态：已接受  
日期：2026-08-20

## 背景

项目已经确定只围绕《灰港：黑潮王座》开发。继续保留无关演示会造成内容边界混乱。与此同时，原稿明确规定白鹭屋地窖暗道开局仅玛莎与奥蒂斯知情，玩家通常在第五章暴雨积水时发现，不能把 `visible=false` 手工改成 `true`。

## 决策

1. 删除旧演示剧本包、产品入口和专用兼容映射；
   初始化存储时只清理同时匹配旧战役 ID 与旧剧本 ID 的演示存档，不影响其他战役；
2. 保留通用物品、关系、幂等和事件能力，但测试不再依赖旧产品剧本；
3. 剧本包升级为版本 3，新增稳定出口 ID、剧情条件和发现定义；
4. 使用 `story.condition_defined/activated` 表达世界条件，使用 `location.exit_discovered` 表达某个角色已经发现出口；
5. 门锁只读取权威背包中的钥匙实例；玩家或 AI 声称有钥匙不生效；
6. 正式灰港内容不虚构原稿未声明的上锁房门。门锁能力由纯规则和合成测试验证，等原稿内容需要时再配置到具体地点。

## 影响

- 正式剧本包版本变为 `0.3.0`，内容指纹随之变化；
- 已存在的 `0.2.0` 存档不会被静默改写，需要显式重置或未来迁移；
- 未发现出口和 GM 条件不会出现在玩家接口中；
- 后续暴雨或 NPC 告知都可以通过权威事件激活发现条件，而不必修改前端或硬编码地点名称。
