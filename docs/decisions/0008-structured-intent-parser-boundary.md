# ADR 0008：模型只提供结构化意图候选

状态：已接受  
日期：2026-08-20

## 背景

自由文本需要 AI 帮助理解，但把模型输出直接当成世界结果会重现“玩家说给过酒就算给过”“一句话发现幕后真相”等问题。模型还可能超时、输出非法 JSON、引用隐藏实体或一次推进多个动作。

## 决策

1. 引入可替换的 `ModelAdapter` 与严格 `ModelIntentProposal`；
2. 解析模型只接收玩家可见且当前相关的最小上下文；
3. 模型输出先做结构校验，再做实体和权限校验；
4. 服务器决定命令 authority、目标规范化和最终参数；
5. 结果性声明进入 `claimed_outcome`，不能直接变成事件；
6. 所有模型失败都安全降级到现有本地解析器；
7. 新增 `intent_attempts` 保存解析审计，但它不是世界状态，也不参与投影；
8. 普通回合接口不返回模型原始请求和输出，只返回已脱敏的解析状态。

## 影响

- 规则引擎和事件投影不依赖模型提供方；
- 未配置模型时，现有网页和存档功能保持不变；
- 后续可以增加 OpenAI 或其他实现，而不修改领域规则；
- 真实模型接入前必须另行配置密钥、模型和调用预算；
- 模型原始输出可审计，但不能作为权威事实或玩家可见知识。
