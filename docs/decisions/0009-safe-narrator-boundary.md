# ADR-0009：AI 叙述器只能包装已确认结果

状态：已接受  
日期：2026-08-20

## 背景

阶段 4A 已允许模型提出结构化玩家意图，但叙述仍是规则文本。直接把完整状态或事件交给大模型生成故事，会同时引入隐藏事实泄漏、凭空修改背包或关系、替玩家决定后续行动以及一次推进过多剧情的问题。

## 决策

增加独立的安全叙述器边界：

- Python 规则先完成一次且仅一次结算；
- 叙述模型只接收确认结果和玩家可见变化；
- 模型候选不能包含事件，必须声明一个节拍并归还控制权；
- 模型只返回前后短氛围，Python 把必需事实原文拼在中间；
- 后端私有隐藏词典在模型调用后检查候选，但绝不进入模型请求；
- 模型失败使用确定性规则原文，不重新掷骰、不重新结算；
- 网络调用在写事务外执行，提交前重新检查幂等键和状态版本；
- 原始请求和响应仅保存在脱离世界状态的私有审计表中。

## 结果

优点：模型文字不能成为状态来源；隐藏上下文攻击面较小；回合仍可重放和幂等；模型停机不会阻断游戏。

代价：第一版不能彻底重写确认事实，文字自由度有限；并发版本冲突时已经付费的模型结果会被丢弃；隐藏片段扫描可能产生保守降级。

## 后续

只有在版本化叙述评估能够证明语义一致性、零隐藏泄漏和可接受延迟后，才考虑放宽逐字事实锚点。
