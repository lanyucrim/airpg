# ADR 0014：长期记忆的全文候选与受约束链接展开

状态：已接受  
日期：2026-08-20

## 背景

阶段 5A～5B 已经建立了确认事件锚定的情节记忆、时间/因果链接和可重建摘要。下一步需要比较结构化检索与全文候选，处理同义表达、较长历史和候选数量压力，同时不能让召回率绕过角色作用域、当前状态路由或来源事件约束。

## 决策

1. 在 SQLite 中增加原文 FTS 表与由同一摘要确定性派生的双字 n-gram FTS 表。它们只索引记忆摘要、战役标识和确定性记忆 ID，是可删除、可重建的候选层，不是事实层；n-gram 表用于弥补 SQLite 默认 tokenizer 无法可靠切分连续中文的问题。
2. `MemoryQuery.search_text` 与 `retrieval_mode = structured / fts / hybrid` 为可选候选策略。默认继续使用结构化查询；FTS 或混合模式最终仍由 `select_memories` 执行实体、事件类型、时间、作用域、状态和字符预算校验。
3. `candidate_limit` 限制初始候选集。查询轨迹同时记录候选总数、上限和 `truncated`，不能把超限丢失静默当作“没有相关记忆”。
4. `expand_links` 默认关闭。开启时只从初始候选沿 `updates` 或 `caused_by` 现有链接展开一跳；链接必须已存在于权威事件派生读模型，不能由 FTS、相似度或模型临时创建。
5. 一跳展开得到的记忆仍必须再次经过全部边界校验。展开不能改变当前状态查询路由，也不能让 NPC 获得不属于自己的私密记忆。
6. 检索轨迹增加展开 ID 和截断指标，但仍不保存私密摘要正文。历史查询与当前状态查询保持分离。
7. 只有在同一语料的结构化、FTS 和混合检索评估证明仍存在稳定的语义召回缺口后，才进入 embedding 实验；向量实验必须使用相同权限和预算边界。

## 研究依据

- LongMemEval（Wu et al., 2024）将时间推理、知识更新和拒答分开评估，本阶段继续分别统计这些能力，而不是用一个相似度分数替代。
- LoCoMo（Maharana et al., 2024）显示长对话中的时间与因果问题不能稳定依赖文本相似度，因此链接仍是结构化来源关系。
- A-MEM（Xu et al., 2025）与 THEANINE（2025）支持保留旧事实并维护显式记忆链接；本项目只接受由事件字段或确定性状态槽产生的链接。
- Generative Agents（Park et al., 2023）的检索经验流启发候选召回，但其自由文本记忆不能替代本项目的事件权威层。

## 被否决的方案

- 直接把 FTS 命中当作最终上下文：会绕过角色作用域和过时事实边界。
- 用相似度自动生成 `caused_by`：相似不是因果证据。
- 超过 Top-N 后静默丢弃：无法区分真正没有记忆与候选预算不足。
- 一次展开整条链接链：容易造成历史爆炸和跨作用域泄漏；首期只允许一跳。
