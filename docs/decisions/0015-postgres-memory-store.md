# ADR 0015：PostgreSQL 运行时存储与可重建长期记忆

状态：已接受  
日期：2026-08-20

## 决策

网页运行时通过 `EventStoreBackend` 接口访问事件、消息、记忆和检索轨迹。SQLite 是离线测试与单机降级实现；配置 `TRPG_DATABASE_URL` 后使用 PostgreSQL。两种实现都必须保持事件追加、幂等、版本冲突和重放语义一致。

PostgreSQL 的全文索引和可选 pgvector 只生成候选，不产生事实。每个候选进入上下文前仍需经过实体、来源、角色作用域、时间、更新链和字符预算校验。未配置 embedding provider 时不启用向量路径。

迁移工具按事件序列导入旧存档，导入后比较事件数量、事件 ID 顺序、来源关系、当前投影摘要和长期记忆重建摘要；任一差异都中止迁移。迁移不会删除旧 SQLite 文件。

## 影响

领域规则保持纯 Python；数据库只承担持久化和候选查询。生产部署需要 PostgreSQL 15+，启用向量时需要 pgvector；测试不需要网络或外部服务。
