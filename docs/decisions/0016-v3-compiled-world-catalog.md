# ADR 0016：V3 内容编译边界与世界自治候选

状态：已接受  
日期：2026-08-20

## 决策

V3 Markdown 是内容源，不是运行时 prompt。编译器按章节分类抽取条目，保存原稿行号、条目片段指纹和全文 SHA-256，输出 `content/campaigns/gray-harbor/v3-catalog.json`。剧本 JSON 包仍是地点、角色、容器、物品和可执行交互的权威结构化入口。

Director 只返回候选；权威服务校验来源事件、世界时间区间、候选类型、重复 ID、可见性和每回合节拍后才提交 `world.reported`。跨日/周/月边界按时间区间逐个结算，不能因玩家长时间等待漏掉世界变化。

## 影响

原稿可以继续细化而不把全文塞进上下文；源文件指纹变化会使编译验收失败，提醒重新生成目录。模型可以读取经过作用域过滤的条目摘要，但不能创建未经编译的人物、物品、任务或地点。
