# ADR 0017：AI 驱动、剧本约束的日常自治

状态：已接受，待阶段 7.5 实施

日期：2026-08-20

## 背景

阶段 7 的环境搜索证明了权威物品和地点边界可以防止 AI 凭空写入世界，但也暴露出静态容器和剧本交互列表无法覆盖开放式日常玩法。玩家在街道寻找食物、临时工作、普通购物、陪伴 NPC 或处理生活琐事，本身是合理行动，不应因为剧本没有逐字列出而被机械拒绝。

另一方面，允许模型自由生成事实会破坏关键道具、NPC 认知、组织时间线、经济守恒和主线条件。

## 决策

采用“AI 驱动候选、剧本约束生成、程序提交事实”的三层结构：

1. 剧本定义硬事实、隐藏事实、关键实体、故事触发条件、地点环境边界和允许的生成政策；
2. AI 根据玩家输入和受控上下文提出地点机会、普通实体、物品、NPC 反应和日常结果候选；
3. Python 验证地点、时间、资源、认知、权限、故事影响和来源，只有通过验证的候选才能成为确认事件。

地点机会不是动作白名单。它限制 AI 可以在哪些类别、范围和影响等级内生成内容，而不要求作者预先写出每一种玩家说法或每一个日常结果。

## 生成边界

AI 可以提出：

- 普通生活物品；
- 临时摊位、路人和短期服务角色；
- 购物、吃饭、休息、工作、闲聊和环境观察；
- 售罄、失败、延期、误会和无结果；
- 受限的即时印象、人情和熟悉度变化。

AI 不可直接提出为事实：

- 主线或重要支线任务；
- 关键道具、唯一证据或隐藏事实答案；
- 永久重要 NPC、组织、城区或建筑；
- 死亡、实名通缉、重大债务或不可逆承诺；
- 绕过剧本硬条件的替代结果。

普通内容若需要持久化或进入故事，必须经过独立的实体晋升或故事绑定事件。

## 代码影响

保留：事件日志、幂等、重放、投影、记忆、认知、法律链和叙述边界。

拆分：

- 从 `engine.py` 拆出地点机会、日常行动、物品、交易和社交规则；
- 从 `scenario.py` 拆出内容 Schema 与 V4.2 编译；
- 增加独立的权威内核迁移阶段：先建立事件存储、命令解析、投影和叙述端口，再逐领域切流，禁止一次性重写；
- 从 `projection.py` 拆出按领域注册的事件处理器；
- 从 `npc_decision.py` 拆出上下文、模型提议和规则验证；
- 从 `game-client.tsx` 拆出地图、场景、背包、行动输入和开发追踪。

采用逐领域迁移，不进行一次性重写。每次迁移保持旧事件和旧存档可重放，并通过新旧摘要对比验证一致性。

## 后果

正面后果：

- 玩家不再被限制为剧本按钮；
- AI 可以形成丰富且连续的日常世界；
- 普通物品和剧本道具可以使用同一套背包与使用规则；
- NPC 决策可以保持主观性而不退化成数值阈值；
- 主线、秘密和关键道具继续受到程序保护。

成本与风险：

- 需要大幅拆分现有领域代码；
- 剧本包需要增加生成政策、物品关键性和地点机会字段；
- AI 候选评估集和真实玩家测试规模必须显著扩大；
- 需要处理临时实体生命周期、经济守恒和模型不可用时的降级。

## 不采用的方案

### 为每个地点手写动作白名单

无法覆盖自然语言和生活行为，维护成本随地点和剧本快速增长。

### 允许 AI 直接写世界状态

会产生无来源物品、越权秘密、关键道具污染、NPC 全知和不可重放后果。

### 只使用固定随机事件表

可以作为降级和内容来源，但不能承担开放式意图理解与情境化 NPC 判断。
