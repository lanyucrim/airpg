# 统一术语

项目中的代码、数据库、接口和文档应优先使用以下概念，避免同一个词在不同模块中表示不同含义。

| 中文术语 | 建议英文名 | 含义 |
|---|---|---|
| 战役 | Campaign | 一条可独立存档和推进的完整游戏实例。 |
| 回合 | Turn | 从接收一次玩家主要输入到返回最终叙述的完整处理单位。 |
| 命令 | Command | 玩家或系统希望执行的操作，尚未成为事实。 |
| 复合命令 | Composite Command | 一次输入中按顺序出现的多个行动或发言组件。 |
| 意图 | Intent | 从自然语言中解析出的行动目标、对象和方式。 |
| 前置条件 | Precondition | 命令执行前必须满足的事实条件。 |
| 判定 | Resolution | 根据状态和规则决定命令结果的过程。 |
| 事件 | Event | 已经发生且不可原地修改的权威事实记录。 |
| 效果 | Effect | 事件对状态造成的可计算影响。 |
| 投影 | Projection | 从事件计算出的当前可查询状态。 |
| 快照 | Snapshot | 为加速重放而保存的某一版本状态副本。 |
| 实体 | Entity | 具有稳定唯一标识的对象，如角色、物品实例和地点。 |
| 物品定义 | Item Definition | 某一类物品的模板，例如“普通红酒”。 |
| 物品实例 | Item Instance | 世界中真实存在的一件物品，例如编号为 `wine_041` 的那瓶酒。 |
| 容器 | Container | 能够持有物品的对象，如背包、箱子、房间或角色手部。 |
| 世界事实 | World Fact | 不依赖任何角色看法的客观事实。 |
| 角色认知 | Character Knowledge | 角色已经获得且能够回忆的信息。 |
| 角色信念 | Character Belief | 角色认为是真的信息，可能与世界事实冲突。 |
| 发言 | Speech | 角色说出的内容；发言本身是事实，但发言内容未必为真。 |
| 关系 | Relationship | 一个角色对另一个角色的定向态度集合。 |
| 声望 | Reputation | 某个群体或地区对一个身份形成的共享评价。 |
| 法律状态 | Legal Status | 某身份在特定管辖区域内的嫌疑、通缉、定罪或赦免状态。 |
| 场景 | Scene | 具有明确地点、参与者、目标和转场条件的局部互动空间。 |
| 剧情节拍 | Beat | 一次有意义但有限的情况变化或信息揭示。 |
| 时钟 | Clock | 表示危机、计划或倒计时进展的离散进度。 |
| 世界时间刻度 | World Time Tick | 从战役纪元起单调递增的整数时间，用于排序、期限和传播延迟。 |
| 剧情线 | Story Thread | 尚未解决且可能继续发展的冲突、承诺、谜团或计划。 |
| 导演提议 | Director Proposal | AI 在规则许可范围内提出的 NPC 反应或剧情表现候选。 |
| 地点机会 | World Affordance | 某地点在特定时间、日程和条件下可合理尝试的行动机会，不等于已经发生的事实。 |
| 日常事件候选 | Routine Event Proposal | AI 根据地点机会提出的普通行动结果候选，必须经过程序验证后才能成为确认事件。 |
| 物品关键性 | Item Criticality | 物品对故事的重要性等级，至少区分 `mundane`、`contextual`、`story_bound` 和 `major_key`。 |
| 故事绑定 | Story Binding | 将已存在的普通或情境物品通过确认事件绑定到剧本任务或故事条件的过程。 |
| 故事影响等级 | Story Impact | 日常候选可能造成的影响范围：`none`、`soft`、`story` 或 `major`。 |
| 叙述 | Narrative | 面向玩家的自然语言展示，不是权威状态。 |
| 因果编号 | Causation ID | 指向直接导致当前命令或事件的上游对象。 |
| 关联编号 | Correlation ID | 将同一回合或业务过程中的多个命令和事件关联起来。 |
| 幂等键 | Idempotency Key | 防止同一个请求被重复执行的唯一标识。 |

## 容易混淆的区别

### 命令与事件

`GiveItem` 表示“尝试赠送”，`ItemTransferred` 表示“物品已经转移”。命令可以失败，事件不能描述未发生的结果。

### 世界事实与角色信念

世界事实可以是“玩家没有送过酒”，守卫的信念可以是“玩家送过酒”。二者允许同时存在。

### 事件与叙述

事件是结构化事实；叙述只是它的一种表现。不同文风可以描述同一组事件。

### 关系与声望

关系通常属于两个具体角色之间；声望通常属于某群体或地区对某个身份的共同评价。
