## 从原稿得到的长期架构要求

1. 客观真相、角色知识、角色推测和流言必须分开。
2. 关系必须有方向、多维度、来源和长期承诺，不是单一好感度。
3. 组织、企业和工会必须独立于首领存在，杀死首领不等于接管机构。
4. 钱、产业、债务、合同和现金流是权力状态，不只是叙述。
5. 世界时钟与 NPC 计划会在玩家不干预时继续推进。
6. 线索必须支持多路径，关键真相不能依赖单次检定。
7. 声望和信息传播有地区、阶层、组织和时间范围。
8. 每回合只推进一个主要行动，把控制权还给玩家。
