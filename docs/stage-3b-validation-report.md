# 阶段 3B 验证报告

## 范围

阶段 3B 把物品请求与给予从“奥伦、红酒、北门钥匙”专用判定抽象为角色、容器和物品驱动的通用交互。

## 已验证行为

- 非演示 NPC 可以交付其真实持有的非演示物品；
- 请求者和目标必须在同一地点；
- 明确点名的目标未持有物品时不会暗中替换目标；
- 物品从真实来源容器转入请求者真实背包；
- 礼物只能从赠送者真实容器转出；
- 只有明确声明接受该物品定义的 NPC 才会接受礼物；
- 礼物关系效果引用真实接受事件；
- 未授权普通物品不会自动交给玩家；
- 模糊物品引用会拒绝，不产生事件；
- 旧阶段 1～2 守卫存档仍能保留钥匙拒绝、关系依据和替代线索；
- 原有幂等、版本冲突、原始消息和事件来源链保持有效。
