### 第一次完整运行：22/32

没有隐藏 ID 泄漏，但发现：

- “王宫”会被模型强行映射到可见的栎木街；
- “她”会被模型猜成唯一有债务话题的玛莎；
- 面向大家的发言会被模型随意指定给某个 NPC；
- 评分器漏算正常说话的时间事件，产生安全误报。

修正：

- 移动目的地必须由玩家原文中的地点名称、别名或小范围错字匹配支持；
- 询问和定向说话必须由角色名称或别名支持；
- “大家”等群体表达由后端规范化为房间听众；
- `safe`/`fallback` 用例使用明确事件白名单。
