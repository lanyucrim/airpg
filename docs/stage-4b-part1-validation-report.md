# 阶段 4B 第一部分验证报告

日期：2026-08-20  
范围：安全叙述上下文、Narration Proposal v1、DeepSeek 适配、审计、事务边界和网页开发追踪

## 实现结果

- 新增独立 `SafeNarrator`，默认关闭真实模型；
- 叙述输入不含玩家原话、原始事件、完整投影或 GM 数据；
- 模型只返回前后短氛围，确认事实由 Python 在中间拼接；
- 非法事件提案、缺失/虚构事实、隐藏片段、多节拍、失败改成功、低置信度和超时均安全降级；
- 叙述模型调用移到 SQLite 写锁之外；
- 新增 `narration_attempts` 私有审计，普通 API 不返回原始载荷；
- 网页开发追踪显示规则叙述、模型采用或安全降级及计量摘要。

## 自动验证

后端完整回归：`115 passed`，总覆盖率 `93%`。

新增叙述测试覆盖：

- 安全上下文不含三个已知 GM 秘密标识；
- 合法候选采用但不改变 Resolution；
- 隐藏事实、秘密出口、非空事件、多节拍和失败改成功被拒绝；
- 超时和低置信度回退到规则原文；
- 回合状态只由确认事件更新；
- 重复幂等请求不再次调用叙述器；
- 叙述调用期间可以取得 SQLite 写锁，证明网络调用不在写事务内；
- 普通回合详情脱敏，后端私有审计仍可追查；
- DeepSeek 使用 JSON 模式，密钥不进入请求正文。

前端验证：ESLint 通过；Vinext 客户端、服务端、RSC、浏览器和 SSR 五阶段构建通过。

## 真实 DeepSeek 与网页联调

真实联调经历了三次受控冒烟：

1. 第一版 Schema 示例把置信度写成 `0.0`，模型照抄后被低置信度门槛拒绝，系统正确采用规则原文；
2. 改为高置信示例后，模型仍把氛围插入必须逐字保留的确认句，被事实锚点拒绝；
3. 协议改为只返回 `atmosphere_before` 与 `atmosphere_after`，确认事实改由 Python 在中间拼接，真实请求被接受。

最终真实样本：意图解析 `model_accepted`，叙述 `model_accepted`，结果为移动到白鹭屋厨房，状态版本 `1 → 2`，确认事件 4 条；叙述使用 516 tokens、约 1.62 秒。随后又从网页实际提交相同动作，开发追踪显示模型意图、4 条确认事件和模型叙述审计，世界位置与时间正确更新。普通 API 的原始叙述请求和响应仍为 `null`。

验收结束后已把正式战役恢复到状态版本 1、白鹭屋一楼大厅、世界时间 0。
