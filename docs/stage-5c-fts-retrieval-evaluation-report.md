# 阶段 5C SQLite 全文检索与受约束展开验证报告

日期：2026-08-20  
状态：第一版实现完成，持续扩充评估语料

## 本轮实现

- 新增可重建的 SQLite FTS5 原文与中文双字 n-gram 候选表；摘要和来源事件仍由事件投影产生。
- `MemoryQuery` 增加可选 `search_text`、`retrieval_mode`、`candidate_limit` 和 `expand_links`。
- 结构化候选与全文候选合并去重，保持确定性排序。
- 一跳显式 `updates`/`caused_by` 展开；展开后的记忆继续执行实体、作用域、时间和预算过滤。
- 检索轨迹记录 `candidate_total`、`candidate_limit`、`truncated` 和 `expanded_ids`。
- 旧 SQLite 存档初始化时自动创建 FTS 表并补齐已有记忆；重建会同步替换 FTS 行。

## 仍需完成

1. 将长期记忆语料扩充到至少 50 个案例，并加入同义表达、别名、否定、模糊时间、多候选冲突。
2. 增加 200 个以上事件的候选压力场景，分别统计结构化、FTS、混合检索的 Recall、Precision、过时事实率、越权率、拒答率、候选成本和截断率。
3. 根据同一语料的失败样本决定是否值得加入 embedding；在此之前不把向量库接入权威回合链。

## 风险边界

FTS 只能回答“哪些摘要可能相关”，不能证明事实、当前状态或因果关系。任何 FTS 命中都必须回到来源事件、角色作用域和当前投影规则中验证。
